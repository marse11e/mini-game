# Fruit Merge

Мобильная браузерная игра про слияние фруктов. Бросаешь фрукты в стакан, два одинаковых
сливаются в следующий по размеру. Цель — дойти до арбуза и не дать стакану переполниться.

Играть: **https://marse11e.github.io/mini-game/**

## Как играть

- Веди пальцем (или мышкой) влево-вправо и отпусти — фрукт упадёт.
- Два одинаковых фрукта при касании сливаются в следующий. Чем крупнее фрукт, тем больше очков.
- Два арбуза исчезают и дают бонус +1000 и по одному бустеру.
- Если фрукты держатся выше края стакана слишком долго — игра окончена.
- На компьютере можно играть с клавиатуры: стрелки двигают фрукт, пробел бросает.

Цепочка фруктов: черника → малина → клубника → лайм → персик → апельсин → яблоко →
гранат → кокос → ананас → арбуз.

### Бустеры

- **Встряска** — подбрасывает и перемешивает фрукты в стакане.
- **Бомба** — нажми на бустер, потом на любой фрукт, и он взорвётся.

Бустеры пополняются по мере набора очков.

### Комбо, задания и прогресс

- **Комбо.** Слияния подряд (пауза не больше 1,6 с) складываются в цепочку. Каждый шаг
  добавляет 25% к очкам, максимум ×2,5.
- **Задания.** Во время партии всегда есть цель: собрать нужный фрукт, сделать столько-то
  слияний, выбить комбо или набрать очки. За выполнение дают бустер, и сразу появляется
  следующее задание посложнее. Игрокам с высоким рекордом первые простые задания не предлагаются.
- **Уровень игрока.** За очки и задания начисляется опыт, который копится между партиями.
  С уровнем меняется звание: от «Новичка» до «Легенды сада».
- **Серия дней.** Если играть каждый день, растёт серия. Со второго дня подряд в каждой
  партии дают +1 бомбу, с пятого — ещё и +1 встряску.
- **Погоня за рекордом.** Игра подсказывает, когда рекорд уже близко, а в итогах показывает,
  сколько очков не хватило.
- **Помощь в трудный момент.** Чем выше гора фруктов, тем чаще выпадает фрукт, которому
  наверху есть пара: на лёгком уровне до 60% бросков, на среднем до 45%, на сложном до 30%.
  В пустом стакане фрукты выпадают случайно.

### Скины

У каждого фрукта три облика: обычный и два открываемых — всего 22 скина.

- Первый открывается, когда фрукт собран нужное число раз за все партии: от 40 черник
  до одного арбуза. Среди них зелёное яблоко, лимон, грейпфрут, жёлтый арбуз.
- Второй — особый, с аксессуаром (корона, бантик, цилиндр, нимб) — открывается на
  определённом уровне игрока: со 2-го (звёздная черника) по 12-й (радужный арбуз).

Скин выбирается в меню «Скины», там же видно, сколько каждого фрукта собрано и что осталось
до открытия. Выбор сохраняется в профиле игрока. Список скинов — массив `SKINS` в `index.html`.

### Награды

19 наград за достижения: первое слияние, комбо ×4 и ×6, 1000 / 3000 / 6000 очков за партию,
арбуз, все 11 фруктов, серии дней, число партий и другие. За каждую дают опыт.
Список — массив `ACHIEVEMENTS`.

### Испытание дня

Раз в день можно сыграть особую партию: фрукты у всех игроков выпадают в одинаковом порядке
(порядок задаётся датой), попытка одна. У испытания своя таблица рейтинга — вкладка «Сегодня».

### Что ещё помогает игроку

- **Сохранение партии.** Игра записывается каждые три секунды, при паузе и при сворачивании.
  Если браузер выгрузит вкладку, партию можно продолжить с того же места.
- **Второй шанс.** Один раз за партию вместо проигрыша можно убрать верхние фрукты и играть дальше.
- **Обучение.** В первой партии игра по шагам объясняет управление и правила.
- **Поделиться.** После партии можно отправить картинку со счётом и ссылкой на игру.

### Фон

Цвет фона подстраивается под самый крупный фрукт партии и плавно меняется: персиковый
в начале, оранжевый после апельсина, красноватый после яблока, жёлтый после ананаса,
зелёный после арбуза. Цвета заданы в массиве `FRUITS` (поле `bg`).

### Фрукты

Все фрукты нарисованы кодом на Canvas в стиле аниме: большие глаза с бликами, румянец,
у каждого свой характер. Они моргают, «дышат», пружинят при ударе и меняют выражение:
радуются после слияния, жмурятся от сильного удара, пугаются, когда стакан почти полон
или когда включена бомба.

### Звук

Фоновая музыка и все эффекты синтезируются прямо в браузере через Web Audio API,
аудиофайлов нет. В меню музыка звучит приглушённо, во время игры — в полную силу,
а когда стакан переполняется, в ней появляется тревожный ритм.

В настройках есть отдельные ползунки громкости для музыки и эффектов и переключатель вибрации.

### На весь экран

- **Android и компьютер**: при старте игры на телефоне включается полноэкранный режим,
  панели браузера скрываются. Ещё есть кнопка в настройках.
- **iPhone**: Safari не даёт сайтам скрывать свою панель. Чтобы играть на весь экран,
  добавьте игру на домашний экран: «Поделиться» → «На экран „Домой“». Оттуда она
  запускается как приложение, без панели браузера. Подсказка об этом есть в меню.

### Уровни сложности

| | Лёгкий | Средний | Сложный |
|---|---|---|---|
| Случайные фрукты | первые 5 уровней | первые 5 уровней | первые 6 уровней |
| Время над краем | 2 с | 1,5 с | 1 с |
| Бустеры на старте | по 3 | по 2 | по 1 |
| +1 бустер каждые | 1500 очков | 2500 очков | 4000 очков |
| Направляющая | до дна | короткая | нет |
| Стакан | обычный | обычный | узкий |
| Скорость падения | обычная | выше | ещё выше |
| Множитель очков | ×1 | ×1,5 | ×2 |

## Игроки и рекорды

### Сервер: общий рейтинг и статистика игроков

Если у игры есть сервер (см. «Свой сервер» ниже), она отправляет туда результаты и сведения
о том, кто играет. Сервер хранит их в JSON-файлах в `deploy/data/`:

- `scores.json` — общий рейтинг: лучший результат каждого игрока на каждой сложности
  и таблицы испытания дня за последнюю неделю;
- `games.json` — итоги партий: счёт, длительность, число бросков и слияний, до какого фрукта
  дошли, использован ли второй шанс (последние 5000 партий);
- `players.json` — игроки по устройствам: имена, система и браузер, размер экрана,
  язык, часовой пояс, громкость музыки и эффектов, вибрация, сложность, число партий,
  опыт, серия дней, рекорды, даты первого и последнего захода.

Личных данных игра не собирает: устройство определяется случайным id, который создаётся
в браузере. На экране выбора имени игрока предупреждают, что сохраняется.

На GitHub Pages своего сервера нет, поэтому без него всё хранится только на устройстве
игрока, а в рейтинге видны игроки этого устройства. Чтобы версия на GitHub Pages тоже
отправляла данные, разверните сервер и пропишите его адрес в `index.html`:

```js
const API_BASE = 'https://game.example.com/';
```

API сервера:

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/leaderboard?difficulty=easy` | топ-10 по сложности; для испытания дня — `difficulty=daily&day=2026-11-14` |
| `POST` | `/api/scores` | результат: `{"name": "Марсель", "difficulty": "easy", "score": 1840}`; в ответе место и сколько очков до следующего |
| `POST` | `/api/games` | итог партии для статистики |
| `POST` | `/api/players` | сведения об игроке: имя, `device`, `settings`, `best`, `gamesPlayed` |
| `GET` | `/healthz` | проверка, что сервис жив |

Имена в рейтинге сравниваются без учёта регистра.

Сводку по собранным данным печатает скрипт:

```bash
python3 deploy/stats.py
```

Он показывает, сколько игроков вернулось в другой день, какие у них устройства и громкость,
сколько длятся партии, как часто используют второй шанс и до какого фрукта доходят.

## Запуск

Игра — один файл `index.html` без сборки. Физика на [Matter.js](https://brm.io/matter-js/),
он и шрифт грузятся с CDN, поэтому нужен интернет.

Локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

С телефона в той же Wi-Fi-сети: `http://<IP компьютера>:8000`.

## Публикация

### GitHub Pages

Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

### Свой сервер (Gunicorn + Nginx)

Схема: Nginx на 80-м порту проксирует запросы в Gunicorn (`127.0.0.1:8000`), тот отдаёт игру
и API рейтинга.

```bash
# Ubuntu, репозиторий в /opt/mini-game
apt install -y nginx
pip install gunicorn
cd /opt/mini-game

# каталог для файла рейтинга
mkdir -p deploy/data && chown www-data:www-data deploy/data

# Gunicorn как сервис
cp deploy/fruit-merge.service /etc/systemd/system/
systemctl daemon-reload
systemctl enable --now fruit-merge

# Nginx (в deploy/nginx.conf впишите свой домен в server_name)
cp deploy/nginx.conf /etc/nginx/sites-available/fruit-merge
ln -sf /etc/nginx/sites-available/fruit-merge /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx

curl http://<домен>/healthz   # ok
```

HTTPS: `apt install -y certbot python3-certbot-nginx && certbot --nginx -d <домен>`.
По HTTPS на телефонах надёжнее работают звук и вибрация.

Переменные окружения сервера:

- `FRUIT_MERGE_DATA` — каталог с JSON-файлами (по умолчанию `deploy/data`);
- `FRUIT_MERGE_CORS` — сайты, которым можно обращаться к API, через запятую,
  например `https://marse11e.github.io`. По умолчанию `*` — все.

## Производительность

Игра рассчитана на слабые телефоны:

- фрукты, их рожицы и стакан рисуются один раз в offscreen-канвасы и потом только копируются;
- разрешение канваса ограничено 2×, частота отрисовки — 60 кадров в секунду;
- если кадр всё равно не успевает, игра сама ступенями снижает разрешение и число частиц;
- под открытым меню сцена не перерисовывается.

## Иконки

Иконки интерфейса — SVG-символы прямо в `index.html` (блок в начале `<body>`), эмодзи не используются:
они выглядят по-разному на разных телефонах.

Favicon и иконки приложения нарисованы в SVG (`icons/favicon.svg`, `icons/app-icon.svg`).
PNG-версии для iPhone и Android генерируются скриптом:

```bash
npm i -D playwright && npx playwright install chromium
node tools/make-icons.js
```
